# Solution And Sales Deck Outline

Use this reference when the purpose is a solution presentation, pre-sales deck, bid deck, sales proposal, or customer proposal.

## Default Length

Use 10-20 slides unless the user asks for a shorter or longer deck.

## Default Outline

1. Cover
2. Agenda
3. Background and objectives
4. Pain points and challenges
5. Solution overview
6. Capability / product value 1
7. Capability / product value 2
8. Capability / product value 3
9. Case study or proof point
10. Implementation plan / roadmap
11. Next steps and contact

Adapt the outline to the provided material and deck length. If the user asks for 5-10 slides, merge sections. If the user asks for 20+ slides, split capability, case study, and roadmap sections.

## Preferred Styles

Start with one of:

- Swiss Modern
- Electric Studio
- Dark Botanical
- Notebook Tabs

Avoid overly playful or decorative styles unless the user explicitly requests them.

## Content Rules

- Keep each slide to one decision or one message.
- Show the buying frame before the product tour.
- Tie capabilities to measurable value, not feature inventory.
- Use risk control and implementation steps for enterprise buyers.
- If content density exceeds one slide, split into a continuation slide.
